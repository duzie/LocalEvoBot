# Tavily Search

Use this skill to perform web searches via Tavily API. It requires the API key in environment variables.

## Usage
- Use for queries that need external web results.
- Prefer concise queries and pass max_results when needed.

## Environment
- TAVILY_API_KEY or tavily_api_key
