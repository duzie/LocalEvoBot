# Memory Directory - 记忆目录

## 文件说明

- **MEMORY.md** - 长期记忆 curated（重要经验、决策、教训）
- **YYYY-MM-DD.md** - 每日笔记（原始对话日志）

## 维护规则

### 每日
- 创建当日笔记文件
- 记录重要对话和任务

### 每 3 天
- 回顾最近笔记
- 提取重要内容到 MEMORY.md

### 每 7 天
- 合并相似记忆
- 删除过期内容

### 每月
- 清理旧笔记（保留最近 30 天）
- 归档到 `archive/` 目录

## 使用示例

```markdown
## 2026-03-08

### 重要任务
- 改造 localevobot 项目，注入"灵魂"
- 创建 SOUL.md, IDENTITY.md, USER.md, AGENTS.md

### 学到的教训
- 记忆系统技术完善，但缺少维护机制
- 需要定期整理 RAG 知识库，避免膨胀

### 用户偏好
- 喜欢直接执行，不喜欢问 permission
- 重视代码验证，不接受"理论上可行"
```
