# Skill

## Name
ppt_gen_skill

## Version
1.0.0

## Description
PPT 生成技能，用于创建生动形象的演示文稿（主题配色、文字排版、图文混排）

## Entry
app.auto_skills.ppt_gen_skill.scripts

## Tools
- create_ppt

## Capabilities
- 支持 4 种主题：professional | vivid | dark | fresh
- 支持正文内容：段落 paragraphs / 要点 bullets / 重点 highlights
- 支持图片：本地图片路径或 http/https 图片 URL（可下载后插入）
- 支持输入兼容：常见字段别名与纯文本自动拆分（见 usage）

## Platforms
- Windows

## Dependencies
- python-pptx
