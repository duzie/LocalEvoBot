# 智能文件读取器技能规则

## 核心原则

### 1. 性能优先
- 大文件必须使用分块或流式读取
- 避免一次性加载大文件到内存
- 根据文件大小动态选择读取策略

### 2. 内存安全
- 监控内存使用情况
- 实现自动内存回收
- 提供内存使用警告和建议

### 3. 向后兼容
- 保持与现有文件读取接口的兼容性
- 支持常见的文件编码格式
- 提供优雅的错误处理

### 4. 智能处理
- 自动检测文件类型和编码
- 根据内容特征选择最佳读取方式
- 提供智能摘要和结构分析

## 工具使用规则

### smart_read_file
1. **文件验证规则**
   - 必须验证文件存在性和可读性
   - 支持相对路径和绝对路径
   - 自动检测文件编码

2. **读取模式规则**
   - `summary` 模式：生成简洁摘要，不超过指定长度
   - `structure` 模式：提取关键结构信息
   - `content` 模式：智能截断，保留重要内容
   - `full` 模式：完整读取，使用优化策略

3. **性能规则**
   - 大于1MB的文件自动启用分块读取
   - 根据文件类型选择最佳分块大小
   - 提供读取时间和内存使用统计

### analyze_file_structure
1. **分析深度规则**
   - 代码文件：分析类、函数、导入
   - 文本文件：分析标题、段落、结构
   - 结构化数据：分析键值对、数组、类型

2. **性能限制规则**
   - 仅分析文件前50KB内容（可配置）
   - 避免深度递归分析导致性能问题
   - 提供分析进度和状态反馈

### generate_file_summary
1. **摘要质量规则**
   - 简洁摘要：突出关键信息，长度可控
   - 详细摘要：包含更多细节，保持可读性
   - 语义摘要：理解文件目的和用途

2. **长度控制规则**
   - 严格遵守最大长度限制
   - 重要信息优先保留
   - 提供截断提示

### optimize_file_reading
1. **优化策略规则**
   - 自适应策略：平衡速度和内存
   - 内存优先：最小化内存使用
   - 速度优先：最大化读取速度

2. **基准测试规则**
   - 测试多种读取方法
   - 提供详细的性能数据
   - 给出具体优化建议

### benchmark_file_reading
1. **测试安全规则**
   - 限制测试文件大小（默认100MB）
   - 控制测试迭代次数
   - 监控系统资源使用

2. **结果报告规则**
   - 提供完整的性能指标
   - 对比不同方法的优劣
   - 给出实用建议

## 错误处理规则

### 1. 文件相关错误
- **文件不存在**：提供清晰错误信息，建议检查路径
- **权限不足**：提示权限问题，建议解决方案
- **编码错误**：自动尝试备用编码，报告最终结果

### 2. 内存相关错误
- **内存不足**：建议使用分块读取或优化策略
- **内存泄漏**：实现自动垃圾回收，监控内存使用

### 3. 性能相关错误
- **读取超时**：设置合理的超时限制，提供进度反馈
- **性能下降**：记录性能指标，提供优化建议

## 安全规则

### 1. 文件访问安全
- 验证文件路径，防止路径遍历攻击
- 限制文件大小，防止资源耗尽攻击
- 检查文件类型，防止恶意文件执行

### 2. 内存使用安全
- 设置内存使用上限
- 监控内存分配和释放
- 实现内存溢出保护

### 3. 性能影响安全
- 控制并发读取数量
- 限制单个文件读取时间
- 监控系统资源使用
