# Skill

## Name
web_validator_skill

## Version
1.0.0

## Description
HTML/JS 代码校验技能。支持 HTML 结构验证、JS 语法检查、CSS 语法检查。

## Entry
app.auto_skills.web_validator_skill.scripts

## Tools
- validate_html: HTML 结构校验
- validate_js: JavaScript 语法校验
- validate_css: CSS 语法校验
- validate_web_file: 自动识别文件类型并校验

## Platforms
- Windows
- Linux
- macOS

## Dependencies
- html5lib (Python 包，可选)
- jsbeautifier (Python 包，可选)
