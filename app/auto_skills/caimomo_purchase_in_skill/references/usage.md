# 菜么么采购入库技能使用指南

## 概述
本技能用于自动化操作菜么么库存管理系统的采购入库功能。通过同步执行的方式，确保操作的可靠性和稳定性。

## 功能特点
1. **同步执行**：所有操作步骤按顺序执行，避免异步操作可能带来的时序问题
2. **智能定位**：支持多种选择器定位方式，提高元素查找的成功率
3. **详细日志**：记录每个操作步骤，便于调试和问题排查
4. **错误处理**：完善的异常捕获和错误处理机制
5. **浏览器保持**：操作完成后浏览器保持打开，用户可继续手动操作

## 使用方式

### 1. 直接调用工具
```python
from app.auto_skills.caimomo_purchase_in_skill.scripts.open_caimomo_purchase_in import open_caimomo_purchase_in_sync

# 同步执行，显示浏览器窗口
result = open_caimomo_purchase_in_sync(
    url="https://v2.caimomo.com/ScmWeb/SCM/Menu4.aspx",
    headless=False
)

# 检查结果
if result["success"]:
    print("✅ 采购入库页面已成功打开")
    print("操作步骤:")
    for i, step in enumerate(result["steps"], 1):
        print(f"  {i}. {step}")
else:
    print(f"❌ 操作失败: {result['error']}")
```

### 2. 在Agent中使用
```python
# Agent会自动加载技能，可以直接调用
result = await open_caimomo_purchase_in(url="https://v2.caimomo.com/ScmWeb/SCM/Menu4.aspx", headless=False)
```

## 参数说明

### url
- **类型**: string
- **默认值**: `"https://v2.caimomo.com/ScmWeb/SCM/Menu4.aspx"`
- **说明**: 菜么么库存管理系统的入口URL

### headless
- **类型**: boolean
- **默认值**: `False`
- **说明**: 是否使用无头模式（不显示浏览器窗口）
  - `True`: 无头模式，后台运行
  - `False`: 显示浏览器窗口，便于观察操作过程

## 操作流程
1. **初始化环境**：启动Playwright和浏览器
2. **打开页面**：导航到菜么么库存管理系统
3. **展开菜单**：定位并展开"库存管理"菜单
4. **选择功能**：点击"采购入库"选项
5. **等待加载**：等待采购入库页面完全加载
6. **验证结果**：检查页面元素，确认操作成功

## 错误处理
技能包含以下错误处理机制：

### 1. 元素定位失败
- 尝试多种选择器定位方式
- 如果所有选择器都失败，会抛出异常并记录错误

### 2. 页面加载超时
- 设置合理的超时时间（30秒）
- 网络空闲时继续执行

### 3. 浏览器异常
- 捕获所有异常并记录详细信息
- 错误时尝试截图保存现场

### 4. 资源清理
- 确保浏览器资源正确释放
- 保持浏览器打开状态供用户继续操作

## 常见问题

### Q1: 为什么选择同步执行而不是异步？
A: 采购入库操作需要严格的顺序执行，同步执行可以确保：
- 菜单展开后再点击子选项
- 页面完全加载后再进行下一步操作
- 避免异步操作可能带来的竞态条件

### Q2: 如果页面结构变化怎么办？
A: 技能使用多种选择器定位方式，包括：
- 文本选择器 (`text=库存管理`)
- XPath选择器 (`//span[contains(text(), '库存管理')]`)
- CSS选择器
- 页面结构遍历

### Q3: 如何调试操作过程？
A: 可以通过以下方式调试：
1. 设置 `headless=False` 观察浏览器操作
2. 查看返回的 `steps` 字段了解每个步骤
3. 错误时会自动截图保存现场

### Q4: 是否需要登录？
A: 本技能假设用户已经登录菜么么系统。如果未登录，需要先进行登录操作。
