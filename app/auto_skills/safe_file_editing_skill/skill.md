# Skill

## Name
safe_file_editing_skill

## Version
1.0.0

## Description
安全文件编辑技能，提供备份、增量编辑、AST 精准替换、代码提取和合并功能，避免文件覆盖问题。
特别针对 Python 和 C# 文件提供语法/结构感知的编辑能力。
