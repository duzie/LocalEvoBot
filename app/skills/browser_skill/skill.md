# Skill

## Name
browser_skill

## Version
1.0.0

## Description
基于OpenClaw的浏览器自动化工具集，提供网页浏览、元素交互、内容提取等功能。

## Entry
app.skills.browser_skill.scripts

## Tools
- browser_open: 打开浏览器并导航到指定URL
- browser_snapshot: 获取当前页面的DOM快照
- browser_click: 点击页面元素
- browser_fill: 填充表单元素
- browser_type: 在当前焦点元素输入文本
- browser_navigate: 导航到新URL
- browser_screenshot: 截取页面截图
- browser_execute_js: 执行JavaScript代码
- browser_close: 关闭浏览器

## Platforms
- Windows
- Linux
- macOS
