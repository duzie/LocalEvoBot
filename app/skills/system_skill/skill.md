# Skill

## Name
system_skill

## Version
1.0.0

## Description
系统级操作与信息查询。

## Entry
app.skills.system_skill.scripts

## Tools
- add_operation_experience: 记录操作经验
- get_operation_experience: 查询操作经验
- search_short_term_memory: 搜索短期记忆（本地对话消息）
- compress_operation_experience: 压缩操作经验
- create_task_plan: 创建任务计划
- read_task_plan: 读取任务计划
- mark_task_completed: 标记任务完成
- append_task_step: 添加任务步骤
- take_screenshot: 截图
- proactive_check: 主动检查任务计划
- maintain_memories: 维护记忆
- add_to_memory_md: 添加到记忆（Markdown格式）
- read_memory_md: 读取记忆（Markdown格式）
- list_processes: 列出所有进程
- delete_image: 删除图片
- get_current_time: 获取当前时间
- run_shell_command: 运行shell命令
- check_process_status: 检查进程状态
