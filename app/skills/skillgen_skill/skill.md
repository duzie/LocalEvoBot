# Skill

## Name
skillgen_skill

## Version
1.0.0

## Description
技能生成与管理。这是一个核心技能，提供了完整的技能生命周期管理功能，包括技能生成、版本控制、回滚机制、依赖管理和热重载。

## Entry
app.skills.skillgen_skill.scripts

## Tools

### 核心管理工具
- **inspect_environment**: 获取环境与技能信息，包括Python版本、操作系统、已安装包等
- **install_packages**: 安装 Python 依赖包，支持批量安装和版本指定
- **scaffold_skill**: 生成新技能脚手架，自动创建目录结构和基础文件
- **reload_skills**: 触发技能热加载，无需重启系统即可生效新技能
- **write_tool_code**: 写入或覆盖工具实现代码，支持自动回滚和版本记录
- **promote_skill**: 迁移技能至核心库，将自动生成的技能提升为正式技能

### 版本控制与回滚工具
- **list_change_versions**: 列出最近变更版本，显示操作历史和时间线
- **rollback_change**: 回滚到指定版本或最近稳定版本，支持精确回滚
- **search_change_logs**: 按关键词检索变更日志，支持模糊搜索
- **export_change_logs**: 导出变更日志（JSON/CSV格式），用于审计和分析

## 核心特性

### 1. 版本控制系统
- **加密存储**: 使用Fernet加密存储变更记录，确保数据安全
- **完整审计**: 记录每次操作的详细信息，包括操作者、时间、状态
- **快照机制**: 文件操作前自动创建快照，支持精确回滚
- **状态管理**: 支持"stable"、"rolled_back"等多种状态标记

### 2. 自动回滚机制
- **原子操作**: 每个工具调用都是原子操作，失败时自动回滚
- **快照恢复**: 操作失败时自动从快照恢复文件
- **状态跟踪**: 记录回滚操作，形成完整的操作历史
- **错误隔离**: 一个工具的失败不会影响其他工具

### 3. 安全特性
- **加密存储**: 所有变更记录都经过加密存储
- **权限控制**: 基于操作者身份记录操作历史
- **数据完整性**: 使用SHA256校验文件完整性
- **密钥管理**: 支持环境变量和文件两种密钥管理方式

### 4. 技能生命周期管理
- **脚手架生成**: 自动创建技能目录结构和基础文件
- **依赖管理**: 自动安装和管理Python依赖包
- **热重载**: 无需重启系统即可加载新技能
- **技能迁移**: 将测试技能提升为正式技能

## 技术架构

### 数据库设计
- **表名**: change_ops
- **字段**: id, created_at, actor, action, status, log_blob
- **索引**: 创建时间、操作类型、状态
- **加密**: 使用Fernet对称加密存储日志数据

### 快照系统
- **存储位置**: app/data/devops/snapshots/
- **文件格式**: 加密的二进制文件
- **命名规则**: 操作ID + 相对路径哈希
- **恢复机制**: 支持精确到文件的恢复

### 密钥管理
- **优先级**: 环境变量 > 密钥文件 > 自动生成
- **环境变量**: DEVOPS_ENC_KEY 或 AUDIT_LOG_KEY
- **密钥文件**: app/data/devops/devops.key
- **自动生成**: 首次运行时自动生成密钥

## 使用场景

### 1. 技能开发
```python
# 生成新技能脚手架
scaffold_skill("new_skill", ["tool1", "tool2"])

# 编写工具代码
write_tool_code("new_skill/scripts/tools.py", code)

# 安装依赖
install_packages(["requests", "beautifulsoup4"])

# 热重载技能
reload_skills()
```

### 2. 版本管理
```python
# 查看变更历史
list_change_versions(10)

# 搜索特定操作
search_change_logs("write_tool_code")

# 回滚到稳定版本
rollback_change()

# 导出审计日志
export_change_logs("audit_log.json", "json")
```

### 3. 错误恢复
```python
# 自动回滚示例
# 当 write_tool_code 失败时，系统会自动：
# 1. 从快照恢复文件
# 2. 记录回滚操作
# 3. 返回错误信息
```

## 安全注意事项
1. **密钥保护**: 妥善保管加密密钥，避免泄露
2. **权限控制**: 确保只有授权用户可以执行敏感操作
3. **审计日志**: 定期检查变更日志，发现异常操作
4. **备份策略**: 定期备份数据库和快照文件

## 性能考虑
1. **快照大小**: 自动清理旧快照，避免磁盘空间占用过大
2. **数据库优化**: 使用索引加速查询，定期清理旧记录
3. **内存使用**: 大文件操作时注意内存使用，支持流式处理

## 故障排除
1. **加密错误**: 检查密钥是否正确，环境变量是否设置
2. **数据库错误**: 检查数据库文件权限和完整性
3. **快照错误**: 检查快照目录权限和磁盘空间
4. **依赖错误**: 使用 install_packages 安装缺失依赖

## 扩展性
1. **自定义加密**: 支持替换加密算法
2. **数据库迁移**: 支持迁移到其他数据库系统
3. **插件系统**: 支持添加自定义工具和功能
4. **Web界面**: 可扩展为Web管理界面

## 最佳实践
1. **小步提交**: 频繁提交小变更，便于回滚
2. **测试验证**: 操作前验证代码和依赖
3. **备份策略**: 定期备份重要数据和配置
4. **权限分离**: 区分开发、测试、生产环境
